# 产品设备信息
* 水泵。
* 水位传感器，输出4-20mA模拟信号。
* 水阀，接受4-20mA模拟信号用于控制开度。
* TM310MM35ECT16U PLC设备，关联的IO设备，
1. TM3DI16数字量输入模块(DI)。
2. TM3DQ16R混合型|/O模块，Q0通道，对应地址为%QX4.0,控制水泵的开关。
3. TM3AI4模拟输入，IWO通道，对应地址为%IW3，4-20mA的量程，对应minimum与maximumINT为4000到20000，用于水位型号的监听。
4. TM3AQ2模拟输出，QWO通道，对应地址为%QW3,4-20mA的量程，对应minimum与maximumINT为4000到20000，用于阀门开度控制。

# 产品目的
通过PLC对水桶内的水位进行控制。用户能够通过设定目标水位值让PLC设备控制水泵，阀门开度来让水桶的水位达到目标值。
