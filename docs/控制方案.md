# 水位控制实现方案

## 1. 物理拓扑与控制原理

```
  左桶(高位)                右桶(低位)
  ┌─────────┐  上管道(重力自流→)  ┌─────────┐
  │  水+泵  │───────────────────→│  水      │
  │         │                    │ 水位传感器│
  └─────────┘←───────────────────└─────────┘
            下管道(泵抽水←) + [阀门]
```

- **上管道**:左桶(高)→右桶(低),重力自流,**持续自然入流**(不可控扰动)。
- **下管道**:右桶→水泵→阀门→左桶,泵一开即抽水,**阀调抽水速度**,水抽回左桶。闭式循环,水量守恒。
- **被控量**:右桶水位。**手段**:抽水阀开度 `%QW3`,辅以泵启停 `%QX4.0`。

### 控制方向(阀在抽水侧,与注水侧相反)
| 水位状态 | 误差 `PV-SP` | 阀动作 | 泵 |
|---|---|---|---|
| 偏高 | + | 开大(多抽水) | 开 |
| 偏低 | − | 关小(少抽,靠自流回涨) | 可停 |

PID 对 `error = PV - SP` 取**正增益**:正值→阀开大抽水。

### 稳态特性(重要)
- 自然入流持续存在,稳态须让"抽水量 = 入流量",故**积分项必需**(否则静差),稳态时**泵常开、阀停在平衡开度**。
- 系统只能**主动降水位**;**注水靠重力自流(被动)**,从低位升到目标只能等。目标水位需 ≤ 自流平衡水位才有意义。
- 若自然入流极小(平衡开度 < 泵开阈值),泵可能周期通断;属正常边界情况,可降低 `rPumpOnThr/rPumpOffThr` 或接受。

### 术语与参数说明

**三个基本量**

| 术语 | 全称 | 含义 | 代码变量 | 类比(定速巡航) |
|---|---|---|---|---|
| **SP** | Setpoint 设定值 | 你**想要**的水位 | `rTargetLevel` | 设定的 100 km/h |
| **PV** | Process Variable 过程变量 | 传感器**实测**水位 | `rLevel` | 仪表盘实际车速 |
| **CV / OUT** | Control Variable 控制输出 | PID 算出的执行器命令 | `rValveCmd`(阀开度 0–100%) | 油门开度 |

控制目标:**让 PV 跟上 SP**。

**误差 error**

`error = PV - SP`(你的阀在抽水侧,符号与教科书 `SP - PV` 相反):
- `error > 0` → 水位偏高 → 开大阀抽水
- `error < 0` → 水位偏低 → 关小阀

**PID 三项与 Kp / Ki / Kd**

```
CV = Kp·error  +  Ki·∫error dt  +  Kd·(d error/dt)
     ────────     ─────────────     ────────────────
       P项            I项                D项
```
代码里 `rInt` = `∫error dt`,`rDeriv` = `d error/dt`。

| 系数 | 名称 | 作用 | 代码变量 | 直觉 |
|---|---|---|---|---|
| **Kp** | 比例增益 | 误差越大输出越大,反映**当前**误差 | `rKp` | "差多少补多少" |
| **Ki** | 积分增益 | 累积历史误差,**消除静差** | `rKi` | "一直差一点就一直加力" |
| **Kd** | 微分增益 | 看误差**变化趋势**,提前刹车防超调 | `rKd` | "快到了提前收油门" |

淋浴调水温类比:P=水太冷就大幅度拧热;I=差着的 1°C 一直存在就持续往热拧直到正好;D=水温上升太快眼看要烫了就提前回拧。水位对象通常是慢响应、积分特性,故默认 `Kd=0`,主要靠 P+I。

**联锁阈值**

| 术语 | 含义 | 代码变量 |
|---|---|---|
| **HH** 高高 | 超高危险限,触发紧急动作(全开抽水) | `rLvlHH = 95` |
| **LL** 低低 | 超低危险限,触发保护(停泵防干抽) | `rLvlLL = 5` |
| **迟滞 hysteresis** | 开/关用两个不同阈值,避免临界点反复通断 | `rPumpOnThr=3 / rPumpOffThr=1` |

迟滞举例:阀开度 >3% 才开泵,<1% 才关泵,中间 2% 是死区,开度在 2% 附近抖动时泵不会一开一关烧触点。

**整定相关**

| 术语 | 含义 |
|---|---|
| **阶跃响应** | 给一个突然的设定变化,观察水位怎么动,摸清对象脾气 |
| **τ (tau) 纯滞后** | 阀动作后,水位**开始**变化前的延迟(水要流一会儿才到传感器) |
| **T 时间常数** | 水位变化到最终值 ~63% 所需时间,反映系统快慢 |
| **Ku 临界增益** | 只用 P、加大 Kp 到系统开始等幅振荡,此时的 Kp |

整定就是根据 τ、T、Ku 算出合适的 Kp/Ki/Kd,见第 5 节。

**信号与标定**

| 术语 | 含义 |
|---|---|
| **4–20mA** | 工业模拟信号标准:4mA=最小,20mA=最大,0mA=断线故障 |
| **量程 range** | 信号对应的数值范围,本模块是 INT `4000..20000` |
| **标定 calibration** | 原始 INT 换算成工程量(%):`(raw-4000)/16000×100` |
| **归一化** | 统一用 0–100% 表示,与传感器实际量程(如 0–1m)解耦 |

**控制循环一句话**:每 100ms,读 PV(水位) → 算 error(与 SP 的差) → PID 算出 CV(阀开度) → 写给阀;P 管当前差、I 管累积差、D 管变化趋势;超高/超低时联锁接管。

## 3. Machine Expert 配置步骤(IDE 内操作,非代码)

1. **设备树**:确认 CPU(M2xx)下挂 TM3DI16 / TM3DQ16R / TM3AI4 / TM3AQ2,模块顺序与地址偏移和上表一致。
2. **TM3AI4 ch0**:Input type = Current,Range 4–20mA,Enable,加滤波(如 50/60Hz)。
3. **TM3AQ2 ch0**:Output type = Current,Range 4–20mA,Enable,建议加 Output Hold/Fault behavior。
4. **TM3DQ16R Q0**:继电器,确认映射 `%QX4.0`。
5. **新建 POU**:`PRG_LevelControl`(PROGRAM,ST),把 `PRG_LevelControl.st` 内容粘入。
6. **任务**:新建周期任务 `T#100ms`,调用 `PRG_LevelControl`。不要放 MAST。
7. **IO Mapping**:核对 `%IW3 / %QW3 / %QX4.0` 与产品说明一致。
8. (可选)**Modbus**:把 `%MW` 区映射到 Modbus 从站,供触摸屏/上位机读写设定值与状态。

## 4. 标定

- **水位**:`4000..20000` → `0..100%`。4mA=4000=0%,20mA=20000=100%。
- **阀门**:`0..100%` → `4000..20000`。4mA=关,20mA=全开(**须与 I/P 定位器约定核对**)。
- **传感器故障**:原始值 `<3800` 或 `>20200` 判故障。

## 5. 调试与整定步骤

1. **标定**:断开 PID(`bAuto=FALSE`),手动写 `%QW3` = 4000/12000/20000,确认阀 0%/50%/100%;同时记录空桶/满桶 `%IW3`,校正 `iRawMin/iRawMax`。
2. **开环阶跃**:手动开阀 30%,记录水位下降曲线,估算纯滞后 τ、时间常数 T、对象增益。
3. **闭环整定**(积分对象,保守起步):
   - 先 `Ki=0、Kd=0`,从小 `Kp` 起;水位对象通常是**积分过程**,P-only 有静差但稳定,用于摸 Kp。
   - 逐步加大 `Kp` 到响应足够快但不振荡。
   - 再慢慢加 `Ki`(从 0.05 起)消除静差;**Ki 过大会振荡**,谨慎。
   - 一般 `Kd=0`;若需抑制超调可加小 Kd(建议改对测量微分,避免 SP 阶跃突跳)。
   - 默认值 `Kp=2.0, Ki=0.1, Kd=0` 仅为起点,**必须现场整定**。
4. **联锁验证**:拔传感器→停泵关阀+报警;强制 HH→泵开阀100%;强制 LL→停泵关阀。
5. **泵频度**:若泵在阈值附近频繁通断,加大 `rPumpOnThr/rPumpOffThr` 间距或略降 `Kp`。

## 6. 关键假设(请确认)

1. 阀装在**抽水/排水侧**(已据此反转控制方向)——✓ 已按描述实现。
2. 阀为**气开型(ATO / fail-closed)**:4mA=关、20mA=全开,与代码默认标定一致,无需取反。✓ 已确认。
   - 失气(气源断)时阀**关死**,抽水停,右桶靠自然入流**上涨**——即使代码触发 `rLvlHH` 全开抽水,失气下阀也无法打开。应配独立的高液位硬报警或溢流口作为最后防线。
3. 水位传感器 4–20mA 对应实际液位范围(0–100% 为归一化;若 0–1m 等实际量程,改标定常数即可,逻辑不变)。
4. 左桶容量足够,不会在持续抽水时被抽空或溢出(本程序不监测左桶)。
5. 是否需要**掉电保持**目标值?若要,给 `rTargetLevel` 加 `PERSISTENT`/`RETAIN` 修饰。
